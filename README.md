# Placement Preparation Portal

A web-based Placement Preparation Portal developed using Python Flask and SQLite.

## Features
- Student Registration and Login
- Aptitude Practice Tests
- Coding Practice
- Python, C and C++ language support
- Coding problem ratings and solved status
- Job Tracking

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run

1. Clone this repository.
2. Install Flask:
   ```bash
   pip install flask
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser and visit:
   `http://127.0.0.1:5000`
